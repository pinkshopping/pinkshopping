Pink Shopping V13 — สั่งซื้อแบบไม่ต้องล็อกอิน (Guest Checkout)

สำคัญ: ต้องตั้งค่า Supabase ก่อนอัปโหลด ZIP
1. Supabase Dashboard > Authentication > Providers > Anonymous Sign-Ins > Enable แล้ว Save
2. อัปโหลด ZIP ไปยังเว็บไซต์ Netlify เดิม
3. ทดสอบเลือกสินค้าจำนวน 1 ชิ้น กรอกชื่อ เบอร์โทร ที่อยู่ และกดสั่งซื้อ
4. ตรวจสอบว่าคำสั่งซื้อปรากฏในหน้า /orders.html ของแอดมิน
5. หากพบ Error: permission denied หรือ authentication required ให้หยุดและส่งข้อความ Error มาตรวจสอบ RPC place_order_with_variants ก่อน ห้ามเปิดสิทธิ์ UPDATE/DELETE ตารางสินค้าและออเดอร์ให้ anon

หมายเหตุ:
- ลูกค้าไม่ต้องกรอกอีเมล/รหัสผ่าน แต่เบื้องหลัง Supabase สร้าง session แบบ anonymous เพื่อเรียก RPC เดิม
- ระบบชำระเงินจริงและใบปะหน้าขนส่งจริงยังไม่ได้เปิดใช้
- แอดมินยังต้องเข้าสู่ระบบด้วยอีเมล/รหัสผ่านตามเดิม
- ต้องตรวจสอบ RLS และสิทธิ์ RPC จริงก่อนเผยแพร่สู่ลูกค้าทั่วไป
- หน้าร้านไม่แสดงรายการออเดอร์ทั้งหมดเพื่อปกป้องข้อมูลลูกค้า
