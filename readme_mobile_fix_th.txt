แก้ไขการสั่งซื้อบนมือถือ: แสดงข้อผิดพลาดข้างปุ่มยืนยันคำสั่งซื้อ ไม่ซ่อนข้อความไว้ด้านบนหน้าเว็บ; แสดงสถานะระหว่างบันทึก; ป้องกันกดซ้ำ; เมื่อ Supabase ยืนยันแล้วจึงแสดงหน้าสำเร็จและบันทึกประวัติในเครื่อง
สำคัญ: ยังไม่สามารถยืนยันว่าปัญหาจริงอยู่ที่ Supabase, network หรือ auth จนกว่าจะทดสอบบนมือถือ หากมีข้อความผิดพลาดให้นำข้อความนั้นมาตรวจสอบต่อ ห้ามกดสั่งซ้ำหากสถานะค้างหลังส่งคำสั่งซื้อจนกว่าจะตรวจออเดอร์หลังร้าน
