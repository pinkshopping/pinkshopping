🎨 ตัวเลือกสินค้า / ขนาด / สูตรหรือกลิ่น / จำนวนต่อแพ็ก

เลือก “แก้ไข” สินค้าในตารางก่อน แล้วเพิ่มตัวเลือกทีละแบบ (แต่ละแบบมีราคา สต็อก และรูปภาพของตัวเอง)

ยังไม่ได้เลือกสินค้า

นำเข้าสินค้าจาก Shopee (เป็นชุด)

ก่อนใช้งานให้รัน V4_MIGRATION.sql ใน Supabase SQL Editor เพียงครั้งเดียว

ข้อมูลตัวอย่างจาก Shopee 117 สินค้าหลัก รวม 140 ตัวเลือก ราคาและสต็อกเป็นข้อมูล ณ วันที่ส่งออกไฟล์

รายการสินค้าและสต็อก (พร้อมรูปภาพ)

รูปสินค้าแสดงจากข้อมูลที่บันทึกไว้ หากไม่มีรูป สามารถกดแก้ไขเพื่อใส่ URL รูปภาพได้
